## What This Is

The Anchor is a short motivational book built as a standalone HTML website. Nine entries written for the authentic builder — the person carrying multiple visions, doing the real work, and refusing to stop even when it's hard.

This is not a map. It is a mirror.

## How to Host Online

This is a single HTML file. You can host it anywhere.

### Recommended Free Options

**Netlify** (easiest)
1. Go to [netlify.com](https://netlify.com)
2. Drag and drop the HTML file
3. Your site is live instantly
4. Connect your custom domain in settings

**GitHub Pages**
1. Create a new GitHub repository
2. Upload the HTML file and rename it to `index.html`
3. Go to Settings > Pages > Enable GitHub Pages
4. Your site is live at `yourusername.github.io/repo-name`

**Vercel**
1. Go to [vercel.com](https://vercel.com)
2. Import or upload the file
3. Deploy and connect your domain
